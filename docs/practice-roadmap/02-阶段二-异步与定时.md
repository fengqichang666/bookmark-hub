# 阶段二：异步与定时

> 目标：把耗时操作拆到异步链路，理解 MQ、定时任务、调度平台、分布式锁的实际用法。
> 预估：1-2 周
> 依赖：阶段一

---

## 一、阶段目标

- Redis 上手：缓存 + 分布式锁 + ZSet 排行榜。
- RabbitMQ：把书签抓取拆成异步。
- `@Scheduled`：单机定时任务体验。
- XXL-JOB：调度平台体验（含分片、手动触发、回刷脚本）。

---

## 二、准备工作：环境

用 docker-compose 起依赖服务，写一份 `docker-compose.dev.yml`：

```yaml
version: '3'
services:
  redis:
    image: redis:7-alpine
    ports: ["6379:6379"]

  rabbitmq:
    image: rabbitmq:3-management
    ports: ["5672:5672", "15672:15672"]
    environment:
      RABBITMQ_DEFAULT_USER: admin
      RABBITMQ_DEFAULT_PASS: admin

  xxl-job:
    image: xuxueli/xxl-job-admin:2.4.1
    ports: ["8080:8080"]
    environment:
      PARAMS: "--spring.datasource.url=jdbc:mysql://host.docker.internal:3306/xxl_job"
```

- [ ] **0.1** 起 Redis / RabbitMQ / XXL-JOB。
- [ ] **0.2** RabbitMQ 管理台 `http://localhost:15672` 能登进去。
- [ ] **0.3** XXL-JOB 管理台 `http://localhost:8080/xxl-job-admin`（账号 admin/123456）能登进去。

## 六、常见坑

- **RabbitMQ 消息丢失**：生产者要开 `publisher-confirms`，消费者要手动 ACK。
- **消息重复消费**：消费方要幂等，用 `bookmarkId + status` 判断。
- **XXL-JOB 执行器注册不上**：`address` 配的要是**能被 admin 访问的 IP**，Docker 里要注意网络。
- **`@Scheduled` 多机重复**：真上生产必须用调度平台或 ShedLock。
- **Redisson 锁 key 冲突**：key 加业务前缀 `bookmark:enrich:lock:{url_hash}`。
